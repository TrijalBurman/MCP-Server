# LocalMind local-drive demonstration

This video contains genuine screenshots captured from the running local browser application.
The application image is uniformly resized; its replies, source cards, and file contents are not rewritten.
Chapter labels and captions are outside the application image. There is no narration.

The video is an edited walkthrough: loading pauses and unused takes are omitted. It is not a latency or accuracy benchmark.

## Workflow

1. Connect and index `/run/media/trijal/HDD/FinalYearProjectByAstra/docs`.
2. Exchange basic greetings.
3. Request the complete indexed-file inventory.
4. Read and summarize each of the seven indexed Markdown documents, with the document source available in the app.

## Recording notes

- This is an edited demonstration of genuine local browser captures. Loading pauses and unused takes are omitted; no assistant reply text is rewritten.
- The initial 9B cold model load reached the application timeout. That attempt and unused question takes are excluded from the selected walkthrough. Original captures remain in the recording folder.
- The indexed folder contained seven Markdown documents and two PNG files. The seven supported Markdown documents were indexed; the two PNG files were skipped.
- The video is a functional walkthrough, not an accuracy or latency benchmark. Some complete-document answers took minutes; those waiting intervals are compressed or omitted.
- The actual generated answers contain known imperfections: the architecture summary ends at an incomplete “State” heading, the hardware summary stops mid-sentence at “Relay Interface: The rel”, the deployment summary has a truncated ending and reports the InfluxDB port as 2086 instead of the source document’s 8086, and the API summary includes an unsupported scope-limitation paragraph. The verification summary also stops mid-sentence at “Test Run: Used Pyth”. Captured replies are preserved unchanged; selected views do not establish that every statement is correct.
- The source document reader is available for checking generated claims. The video includes a deployment source check showing the original 8086 port.
- The API section shows a warm-model retry after a cold-load timeout; it does not represent an error-free first attempt. Repeated prompts in the actual conversation remain visible.
- The inventory and API review screens are selected from a later review of the same saved conversations. The video orders these genuine captured views by demonstration topic.
