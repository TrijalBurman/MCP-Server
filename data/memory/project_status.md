# Project Status

## Overview
Local-First Agentic Knowledge Copilot — fully offline AI assistant with persistent project memory, local RAG, and MCP tools.

## Stack
- LLM: Ollama (qwen2.5:7b) — GPU-accelerated on RTX 5050
- Embeddings: all-MiniLM-L6-v2 (sentence-transformers)
- Vector DB: ChromaDB (local persistent)
- Memory: Plain Markdown + YAML
- Agent: ReAct loop (pure Python)
- Frontend: Streamlit

## Research Question
Does exposing persistent project memory through a custom MCP server improve the effectiveness and consistency of a local RAG-based agent compared with a stateless RAG system?
